# 验证范围

基础流程使用独立 H2 数据库与真实 HTTP 接口验证，不发送用户小说模型任务。

验证内容包括：

- 创建作品、确认大纲、暂停与失败重试。
- 一次综合审核进入记忆步骤，普通问题修改正文，重大变更等待确认。
- 账号隔离、文件读取、正文来源和过期版本拒绝。
- 局部修改保留其他原文，拒绝重复匹配、范围重叠和无效标识。
- 正文、记忆版本与进度的事务提交，暂停结果保留。
- 预算、费用核对、调用记录和技能来源指纹。

真实模型的写作质量、上下文消耗和缓存命中需要固定正文与设定进行对比。程序校验能够检查引用存在和结构合法，无法证明所有语义正确。没有真实模型对比时，不声明具体 token 节省比例或连载质量已经通过验证。
