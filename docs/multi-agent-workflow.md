# 创作流程

当前版本：1.21.0。

| 组件 | 职责 |
| --- | --- |
| PlannerAgent | 生成当前阶段大纲，等待用户确认 |
| WriterAgent | 根据批准章纲生成正文，按检查意见修改 |
| ChapterReviewAgent | 一次检查连续性、推进和表达，返回结论与具体问题 |
| MemoryExtractionAgent | 提取本章必要变化，使用局部修改更新 Markdown |

WorkflowService 直接决定下一步骤：大纲确认后写作，审核通过后更新记忆，文件校验通过后提交章节，阶段结束等待确认。普通修改最多3轮；重大变更、预算不足或任务失败时停止推进。

每个任务创建独立执行上下文，正式作品状态由数据库和 Markdown 版本提供。读取工具仅包含目录、关键词搜索、文件读取、大纲和正文来源核对。AgentScope 提供模型执行与工具调用，ConversationCompactor 汇总工具历史；所有真实请求记录用量和费用。

记忆提取不预加载整批主题。程序按文件指纹及唯一原文匹配应用修改，其余内容保留。正式文件不可变，准备完成后将章节、文件清单、版本及下一任务在同一事务内提交。

阶段大纲、阶段完成、重大剧情变化和重要历史修改继续遵守人工确认。暂停期间完成的任务保存 READY，恢复时核对正文与记忆版本。历史任务和费用只作为记录保留，已移除功能的任务不再自动调度。
